## 4. 사람이 확인할 것

1. **변경 가능성으로 요청 안 한 경로 12개** (2.4 표). 브라우저에서 직접 동작을 보며 확인. 특히 `/address/saved`, `/saved-payment-methods`는 이름만 보고 제외한 것이라 읽기 경로인지 확인 필요.
2. **/ftp 파일 목록과 각 파일** — 본문이 잘려 못 본 부분. robots.txt에 Disallow로 적혀 있음.
3. **/rest/memories 전체 응답** — 잘린 뒤쪽 항목, `password` 값의 형태, 어떤 필드까지 내려오는지.
4. **/rest/captcha** — 응답의 `answer`가 어느 기능에서 검증에 쓰이는지.
5. **/api/Feedbacks의 지갑 복구 문구처럼 보이는 문자열** — 실제로 쓰이는 값인지, 공개 목록에 있는 것이 의도인지.
6. **잘린 응답** — /api/Challenges, /api/Hints, /api/Products, /api/Quantitys, /rest/memories, /ftp.
7. **401이 나온 경로** (/rest/user/authentication-details, /rest/image-captcha, /rest/wallet/balance, /api/Users, /api/Addresss, /api/BasketItems, /api/SecurityAnswers, /api/Complaints, /api/Cards) — 로그인이 필요해서 이번 정찰 범위에서는 확인 못 함.
8. **/rest/order-history, /profile의 `Blocked illegal activity` 500** — 인증 없이 보냈을 때의 정상 동작인지, 다른 원인인지.
9. **/rest/user/security-question?email=** — 쿼리 없이 요청했을 때의 오류 형태만 봤고, 쿼리를 넣은 동작은 시험하지 않음.
10. **/rest/country-mapping** — 본문도 Content-Type도 없는 500.
11. **/engine.io, /socket.io** — 왜 화면 페이지가 오는지 (3.7).
12. **포트 37469, 42201** — 어떤 프로세스인지(`ss -ltnp` 같은 로컬 확인은 직접 실행). 37469의 지문에 이 프로젝트 디렉터리가 cwd로 찍혀 있음.
13. nmap이 포트 3000을 `ppp?`로 표시한 것은 서비스 미식별 때문이고, 지문 응답으로는 Juice Shop(HTTP)이었음.
